# PsyTech

Here's the release page for the psytech scheduling app

## Installation

Open up a terminal and run one of the following commands:

### macOS/Linux
```sh
curl -fsSL https://raw.githubusercontent.com/ndortega/psytech-releases/refs/heads/master/install.sh | sh
```
To install a specific version:
```sh
curl -fsSL https://raw.githubusercontent.com/ndortega/psytech-releases/refs/heads/master/install.sh | sh -s -- <version>
```

### Windows (PowerShell)

Open up powershell and run one of the following commands:

```powershell
irm https://raw.githubusercontent.com/ndortega/psytech-releases/refs/heads/master/install.ps1 | iex
```
To install a specific version:
```powershell
$Version = "<version>"; irm https://raw.githubusercontent.com/ndortega/psytech-releases/refs/heads/master/install.ps1 | iex
```
